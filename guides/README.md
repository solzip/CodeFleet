| [Host Core](host-core-guide.md) | 기본 준비, 검증 Backend와 보장 범위 |

| [Alpha CLI](alpha-quickstart.md) | 기존 Alpha 경로의 명시적 계약과 사용법 |

제품 설계는 [docs](../docs/README.md), 개발·기록 규칙은 [CONTRIBUTING](../CONTRIBUTING.md)을 따른다.
