## Legacy 검사에 필요한 보존본

현재 트리의 역사 보존 Markdown은 1개다. <!-- fact: docs-indexed = 1 --> <!-- fact: docs-on-disk = 1 -->

| 문서 | 역할 |
| --- | --- |
| `archive/2026-08-13/ARCHIVE.md` | Legacy 표지의 측정값을 대조하는 보존 계약 |

새 사용 안내와 상태 문서는 docs 안내에서 찾는다. 보존본은 현재 제품의 기능 수용을 증명하지 않는다.
